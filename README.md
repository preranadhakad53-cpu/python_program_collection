### 5. Conceptual Questions

**Q1. How can a Python dictionary be modified at runtime?**

Python allows new keys to be added to a dictionary without modifying a predefined structure. This flexibility is useful when handling dynamic data, but it can be risky because Python does not automatically ensure that every dictionary contains the expected keys.

**Q2. Where does the data type come from in a Python dictionary?**

In Python, the type comes from the value assigned to a key. Unlike a C structure, a Python dictionary does not require explicit type declarations for its values.
